# Ракурс — кабинет менеджеров

Приватный пакет для единственного аккаунта `rakurscrm.amocrm.ru`.
Карточка описывает работу с установками, контактами и сделками.
Кнопка «Открыть кабинет» ведёт в раздел «Установки». Кнопка
«Активировать» появляется, когда Core подтверждает, что приватное
подключение ещё не активно. Core API должен поддерживать маршрут
`GET /api/v1/company-cabinet/activation`.

## Сборка

```sh
python3 integration-packages/rakurscrm-manager/pack.py --output /tmp/widget.zip
```

## Установка

Создайте в rakurscrm отдельную приватную интеграцию «Ракурс — кабинет
менеджеров». В настройках загрузите ZIP и укажите согласованный с Core
OAuth Redirect URI. Для этой интеграции зарегистрируйте собственные
Client ID и Client Secret в Core через действующий секретный контур.
Установите виджет в rakurscrm и подтвердите права для сделок.

Зафиксируйте ID аккаунта, интеграции и созданной установки для привязки
`COMPANY_CRM_*` в Core и `PLATFORM_COMPANY_*` в Platform. В кабинете
откройте «Установки» → «Настройка сделок» и задайте общую воронку
и начальный этап.
Сервер использует эту привязку для обращений к amoCRM после закрытия
браузера. ZIP содержит интерфейс настроек и ссылку на кабинет.

Для обновления откройте редактирование уже созданной приватной интеграции
в amoМаркете и загрузите новый `widget.zip` поверх текущей версии.
Название и описание, которые amoCRM выводит вокруг карточки, берутся
из настроек самой интеграции. Заголовок внутри карточки обновляется
из ZIP.

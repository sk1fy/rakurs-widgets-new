# Динамические поля от Ракурс

Самостоятельный виджет amoCRM с кодом `rkrs_advanced_fields`. Все модули карточек, редактора и активации, стили и изображения входят в один пакет amoCRM. Исходники находятся в `widget/`.

## Сборка

Запустите `python3 pack.py` из этого каталога и загрузите `dist/widget.zip` в интеграцию amoCRM. amoCRM раздаёт файлы виджета из загруженного пакета.

`PLATFORM_ACCESS_ORIGIN` задаёт HTTPS origin для чтения лицензии. По умолчанию сборка предполагает, что публичный прокси Core также обслуживает `/v1/access/`. Если Platform использует отдельный origin, задайте его при сборке. Для работы из amoCRM публичные маршруты должны поддерживать браузерные запросы с домена аккаунта, включая preflight для заголовков авторизации.

## Установка и доступ

1. Пользователь принимает условия и устанавливает интеграцию штатной кнопкой amoCRM.
2. В настройках установленного виджета пользователь вводит телефон. Виджет сохраняет `system_contact` через Web SDK и отправляет в Core телефон и согласие `contact-v1` после подтверждения сохранения. При закрытии модалки незавершённая активация продолжается в той же вкладке.
3. После активации виджет получает proof у Core и читает `GET /v1/access/{amo_account_id}/rkrs_advanced_fields` с этим proof. Состояние полей зависит от `active`, срок в настройках берётся из `valid_until`. При ошибке доступ проверяется повторно.
4. Для обещанных в туре 90 дней в каталоге Platform нужна привязка фактической OAuth-интеграции к продукту `rkrs_advanced_fields` с однократной политикой `top_90d`. Срок назначает сервер. Локальная сборка не регистрирует интеграцию и не меняет тариф.

Ссылка на инструкцию ведёт на прежнюю публичную страницу Ракурса. Кнопка «Продлить» открывает переписку с поддержкой.

# Прототип «SLA: контроль первого касания»

Интерактивный инструмент внутри демонстрационной CRM. Бэкенда нет: отчёт, таймеры, журнал и настройки живут в браузере.

## Запуск

Нужны Node.js 22.12+ и npm.

```sh
cd /Users/nikpeskov/Projects/rakurs/rakurs-widgets-new/rkrs_sla_first_touch/widget-app
npm ci
npm run dev
```

Открыть `http://127.0.0.1:5175/`. Команда сначала собирает удалённый модуль, затем стенд. Стенд грузит виджет настоящим RequireJS: `release.json` → UMD с хешем → слот `data-rkrs-sla-slot`.

После правки `src/` или `../widget/script.js` выполните `npm run release` и обновите страницу. Оболочка CRM обновляется Vite, сам виджет намеренно приходит отдельным AMD-релизом.

## Экраны

Вкладки внутри виджета:

- **Отчёт** — период, фильтры, четыре KPI, каналы, скорость, рейтинг, heatmap, таблица когорты и CSV.
- **Воронка** — две воронки с теми же маркерами SLA. Смена вкладки не запускает новый отсчёт.
- **Настройки** — норматив, окно, дни, пояс, воронки, переназначение, примечание, подсветка, праздники, пре-алерт, критическая задача, часы дайджеста и итога дня.
- **Уведомления** — пре-алерт, критическая задача, дайджест, итог дня, журнал и макеты подписчиков.
- **Подписка** — короткий локальный статус без цен и оплаты.

Карточка сделки открывается боковой панелью из отчёта и с канбана. Клавиша Escape закрывает popup, затем карточку.

## Демо-часы и данные

Часы одни для таймеров, графиков, журнала и таблиц. Старт заморожен на вторнике **6 октября 2026, 11:00** (`Europe/Moscow`), чтобы KPI не плыли. Можно продолжить ход, прибавить 5/30/60 минут, перейти на следующее рабочее утро, выбрать сценарий или сбросить данные.

В фикстуре 34 сделки, 4 сотрудника и 2 воронки. Среди них есть ответ ровно на границе 30 рабочих минут (пятница 17:50 → понедельник 09:20), вечернее назначение, праздник 7 октября 2026, крупный бюджет, переназначение и ручная заметка. Сценарий «Четверг после праздника» переводит часы на 8 октября 09:15, чтобы показать 10 рабочих минут по сделке «Пекарня Мост — ночная заявка».

Сценарии «Загрузка», «Пустые данные» и «Ошибка данных» не рисуют благополучный ноль. Пустая выборка пишет «нет данных». Если сравнивать не с чем, дельта не считается.

## Как считается

Коротко это же написано в отчёте, блок «Как считается».

- Рабочее время — пересечение интервала ожидания с окном кабинета. По умолчанию пн–пт, 09:00–18:00, `Europe/Moscow`. Конец окна не позже начала — ошибка, цифры не выдумываются.
- На границе норматив ещё соблюдён (`elapsed <= target`). Нарушение — строго больше.
- Примечание учитывается только если настройка включена и автор — текущий ответственный. Входящее, нулевой звонок, задача, бот и система таймер не останавливают.
- Переназначение в ожидании либо сбрасывает эпоху, либо сохраняет старт. После касания обычное переназначение итог не меняет.
- Скрытие подсветки сделок, созданных вне графика, только визуальное.
- Праздники — явный список дат выбранного демокалендаря, не календарь поставщика.
- Группы скорости — решение демо: ≤ норматив, (норматив; 2×], > 2×, отдельно «без ответа».
- Пре-алерт один раз на сделку и не является касанием. Если ожидание уже больше 2× норматива, он пропускается.
- Критическая задача — эскалация после нарушения, один раз на сделку. Бюджет сам по себе до нарушения задачу не создаёт.

## Что только имитируется

Нет OAuth, нет запросов в amoCRM, нет Telegram и нет отправки сообщений. Кнопки «Предпросмотр» и «Смоделировать отправку» показывают локальный текст и строку журнала. Подписчики, бот и подписанная ссылка помечены как макет. Вкладка «Подписка» не содержит цен и ничего не блокирует. Звонок, письмо и сообщение в карточке сделки только меняют локальную историю.

Состояние пишется в `localStorage` по ключу `rkrs_sla_prototype_v1:<accountId>:<userId>`. В стенде это аккаунт `999101` и пользователь `999102`, поддомен `demo`.

npm run build:preview     # автономный стенд в dist-preview/

Тесты проверяют чистые функции времени и метрик: границу 30 минут через выходные, 10 минут через праздник, пре-алерт на 22 мин 30 с, нулевой звонок и входящее, канал «Звонок», примечание, политики переназначения, одну критическую задачу, пустую выборку и отсутствие бесконечной дельты.

## ZIP

Плейсхолдер в `../widget/script.js`: `__RKRS_SLA_ASSETS_URL__`. После выкладки `dist-remote/` на свой HTTPS:

```sh
npm run package:widget -- --assets-url https://YOUR-HOST/widget-assets
```

Команда собирает `dist-package/rkrs-sla-prototype.zip`: загрузчик, manifest, локализация и изображения, без UMD. Это по-прежнему демонстрационная версия без бэкенда.

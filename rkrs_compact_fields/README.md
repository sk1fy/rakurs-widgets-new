# Удобные поля

Исходники пакета amoCRM находятся в `widget/`. Команда `python3 pack.py`
собирает `dist/widget.zip` для существующей интеграции в amoMarket.

Кнопка «Переавторизоваться» запускает OAuth через Core для интеграции
`rkrs_compact_fields`. После OAuth Core сохраняет установку и переносит в
каталог менеджеров ID установщика, полученный от amoCRM для первой
установки или переустановки. Повторная авторизация сохраняет установщика
текущего эпизода.

Для рабочего подключения зарегистрируйте в Core существующий OAuth client
amoMarket и его секрет. Свяжите интеграцию с продуктом `rkrs_compact_fields`
в каталоге Platform и настройте правило FREE и автоматическое подключение
аккаунтов. Redirect URI в amoCRM и в записи Core должен совпадать с
`https://core.rkrs.ru/oauth/amocrm/callback`. Прокси должен обслуживать
этот callback, старт OAuth и `GET /api/v1/widget/connection`
с CORS для домена аккаунта amoCRM.

Виджет передаёт Core одноразовый токен amoCRM для подтверждения установки.
Форма контактных данных и пульс используют прежние маршруты Ракурса.

Локальные тесты проверки подключения запускаются командой
`node --test tests/access.test.cjs`.

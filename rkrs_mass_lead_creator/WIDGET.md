# Массовое создание сделок

Статус: локальный прототип. Тонкий загрузчик лежит в `widget/`, UMD и симулятор CRM — в `widget-app/`. Запуск, экраны и допущения: [widget-app/README.md](widget-app/README.md).

```sh
cd /Users/nikpeskov/Projects/rakurs/rakurs-widgets-new/rkrs_mass_lead_creator/widget-app
npm ci
npm run dev
```

Стенд: `http://127.0.0.1:5176/`.

## Что показывает прототип

Путь из списка контактов: отфильтровать, выбрать страницу или всю выборку фильтра, задать воронку и порядок менеджеров, проверить план обзвона, создать сделки и задачи, увидеть смешанный результат. Интерфейс на русском. Данные вымышленные, на экране есть метка «ДЕМО».

Создание происходит только в локальной модели браузера. OAuth, amoCRM API и оплата не подключаются.

## Экраны

- Список контактов с квотой, фильтрами и панелью «выбрано N».
- Настройка операции и график кабинета.
- План: менеджеры, дни, таблица контактов, предупреждения.
- Прогресс и результат со статусами «сделка и задача созданы», «сделка создана, задача не создана», «сделка не создана».
- Локальная карточка сделки.
- Панель «Демо» со сценариями, пустым списком, ошибкой данных и сбросом.

## Допущения

- Шаг расписания считается из длины рабочего окна, а не из длительности задачи. Перегрузка, когда длительность больше шага, не скрывается. Задача не ставится задним числом. Выходные и даты-исключения пропускаются. Пятничный хвост при праздничном понедельнике попадает на вторник.
- Квота 250 контактов в локальный день кабинета и дневной лимит задач менеджера — разные ограничения. Превышение квоты останавливает запуск целиком.
- Открытая сделка не выкидывает контакт из партии. Отдельный новый запуск может создать ещё одну сделку.
- Контакт без телефона нужно исключить вручную. Номер не подставляется.
- Готовую партию нельзя отменить одной кнопкой. Полный сброс демоданных есть только в панели «Демо».
- Повтор после сбоя создаёт только недостающий шаг и не копирует уже созданную сделку.

Запись в CRM имитируется. Установка в аккаунт и публикация для этого прототипа не нужны.
